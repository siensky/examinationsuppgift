# examinationsuppgift

Vi har skapat en simpel hemsida byggt med HTML, CSS och JavaScript som examinationsarbete i kursen Bootcamp i Chas Academy. Syftet med detta arbete är att visa upp våra kunskaper i frontend-utveckling. 

Denna sida innehåller:
- Responsiv layout
- Navigeringsmeny med länkade sidor
- Tillgänglighet enligt WCAG
- CSS styling
- API


Projektet har körts och testats genom att klona repot och öppna index.html filen i webbläsare. I webbläsaren har vi testat websidan med olika fönsterstorlekar för att konstatera att den är responsiv. Vi har testat våra JavaScript funktioner i konsolen.
