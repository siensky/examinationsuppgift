# examinationsuppgift


We have created a simple and responsive webpage, built with HTML, CSS and JavaScript as a examination project in the bootcamp course in Chas Academy. The purpose of this project is to show our knowladge in frontend development and how to build a user-friendly accessible website. 

The webpage includes:
- Responsive layout that is fit for different screen sizes
- Navigation menu with linked pages and a hamburger menu for mobile devices
- Accessibility according to WCAG
- Dynamic contant fetcched from a API

Our project has been used and testet by cloning the repo and opening the index.html file in a web browser. We have tested the website in different sizes to assure that it is responsive. The JavaScript functions have also been testet in the browsers console.
